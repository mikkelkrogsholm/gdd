Status: verified after fixes for R053–R054.

R053: Lossless decimal roundtrip in the parser does not protect subsequent binary float/integer comparisons. minimum=1e23/maximum=99999999999999995000000 can therefore yield a false model PASS, while the mathematically equal interval minimum=100000000000000000000000/maximum=1e23 can be rejected. The same cause affects actually supported extension assertions (minimum/maximum/exclusive bounds, multipleOf, const/enum/uniqueItems) and core enum uniqueness. Two independent reviewers share the reproduction; the fix must cover the numeric semantics used without storing non-JSON objects in the model, hashes, or artifacts.

R054: invalid_record_ids already knew about an evidence.check_revision contradiction, but validate_records did not diagnose it. With unrelated evidence, the model dimension and the entire CLI run could therefore be PASS/exit0 without any diagnostic. The hash can be checked locally, even with a historical spec revision; this does not rebind historical targets. CHECK_REVISION_MISMATCH must be reported globally while preserving independent implementation and authorization results.
