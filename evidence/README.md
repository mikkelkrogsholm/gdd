# Verification evidence and English presentation

Current English verification is collected in [the localization review](english-review.md).
The repository's current prose, models, interface, generated graph and screenshot
presentations are English. The GDD format remains 0.2; package 0.5.1 and renderer
0.1.4 identify the English release.

Earlier reviews describe executions against earlier source states. Their dates,
results, tool versions, hashes and revision claims have not been rebound to the
translated sources. Their original bytes are available in the
[pre-English Git state](https://github.com/mikkelkrogsholm/gdd/tree/2ced75a5cdd4e5521282c5e9c596da7c2dc83aac).
Translated prose is an English presentation of those historical results.

The current historical screenshot paths contain new English reconstructions.
They are not the original review-round captures. The
[screenshot provenance map](english-screenshot-provenance.json) records each
original Git hash, replacement hash and fresh capture path. The
[text presentation map](english-presentation-provenance.json) similarly records
translated tracked artifacts without changing their old execution claims.

The already-English Graphify raw observations, producer assets, native-agent
model, native run event chain and application evidence retain their original
bytes. Proper names, technical identifiers and intentional Unicode test data
are data rather than translated explanatory prose.
