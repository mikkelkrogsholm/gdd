# Archived GDD 0.2 standard

These standard chapters, core schemas and concert example were copied from the
English GDD 0.2 state before authoring GDD 0.3. Their bytes retain that contract.
The reference tool dispatches 0.2 manifests/fragments to separately preserved schemas
and applies the original semantics. Current files describe GDD 0.3.

The complete historical repository, including links, tools, examples and evidence,
is available at [the English 0.2 commit](https://github.com/mikkelkrogsholm/gdd/tree/05946abfb0417d05d3c35fbec01ec1fe6a896749).
Relative links in copied historical documents refer to that original layout; this
bounded archive is not a separately packaged release. Native-agent execution records
remain in their original location and have not been rebound to the new standard.

See [migration](../../standard/MIGRATION.md) for the intentional 0.3 additions.
